# WhereAmI

É um aplicativo simples para você descobrir onde você está.

Clone o repositório pelo Android Studio:
```text
git@github.com:drmcarvalho/WhereAmI.git
```

Ou pelo git linha de comando:
```shell
git clone git@github.com:drmcarvalho/WhereAmI.git
```

Em seguida, no Android Studio builde a aplicação e execute.
